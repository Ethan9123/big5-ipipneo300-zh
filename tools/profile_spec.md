# 243 人格画像 · 写作规格

## 背景（必须先理解，否则会写错口吻）

站点是 IPIP-NEO-300 中文版。5 个维度各切成 低 / 中 / 高 三档（百分位 ≤30 / 30–70 / ≥70），
组合出 3⁵ = 243 个格子。**每一格都有真人落入**（145,388 人样本里最稀有的一格也有 24 人）。

项目测量误差模拟得到的组合档位保持率约为 **47.2%**，并非真实重复施测的重测一致率，不能用来预测个人下次会落在哪一格。参考样本中 66.8% 的人至少有一个维度距 30/70 分界不到 5 个百分位点，说明分档容易受边界附近的分数变化影响。

## 证据与措辞约束（优先于下文旧示例）

- 分数支持倾向描述，不支持断言个人经历、关系质量或工作能力。生活场景只能作为供读者核对的例子。
- 不把低尽责性等同于不可靠，不把低神经质等同于缺少共情，不把中等分数等同于缺少主见。不能为了凑齐优缺点而推导没有依据的代价。
- 不以“扎人”、吹捧或让人认同为准确性的标准。下文旧示例中的绝对判断不应照搬。
- 叙述应区分分数依据、解释性推测与可核对的行为；没有专门验证的数据，不应声称某种模式必然让分数上移或提高准确率。

**这个数字决定口吻。** 页面会自动标出哪个维度贴着边界，并把邻近画像也给用户看。
所以你写的不是"这个人是谁"，而是"分数落在这个区域，通常意味着什么"。

## 硬性禁止

1. **不许起类型名**。没有"风暴型创作者""指挥官"之类。用户看到的标题由程序生成，你不要造名字。
2. **不许写"你天生…""你注定…""你就是…"**。改成"你目前的分数…""这个组合通常…""大概率…"。
3. **不许吹捧**。这不是星座运势。站点原文的立场是："低、中、高分本身无所谓好坏——
   同一个特质水平，对很多事情无关紧要，对某些事有帮助，对另一些事有妨碍。"照这个来。
4. **不许写成诊断**。不出现抑郁症、焦虑症、ADHD、自闭等任何临床词汇，也不暗示。
   高神经质写成"情绪起伏大"，不是"你可能有情绪障碍"。
5. **不许给出会影响他人权益的建议**（招聘、择偶筛选别人、评判他人）。建议只对读者自己。
6. **不许用"内向者/外向者"当身份标签**，用"外向性分数偏低的人"这种说法。

## 口吻

- 克制、具体、像一个了解你但不奉承你的朋友。
- **优先写可观察的行为，而不是内心状态。** 不写"你很焦虑"，写"你会在发出消息后反复看有没有回复"。
- 缺点部分要真的扎人，但不羞辱。指向行为和代价，不指向人格价值。
- 允许出现"这条对你杀伤面积最大""别急着立志"这类口语化的转折，站点本身就是这个语气。
- 简体中文。不要用英文术语（写"尽责性"不写 Conscientiousness）。

## 每个维度各档的含义（务必统一，跨 agent 一致性靠这个）

| 维度 | 低（≤30） | 中（30–70） | 高（≥70） |
|---|---|---|---|
| 开放性 O | 偏好熟悉、具体、经过验证的东西；对抽象和新奇兴趣有限；务实 | 既能接受新事物也需要稳定感，取决于场合 | 好奇、爱抽象、审美需求强；容易被新想法牵走 |
| 尽责性 C | 随性、计划性弱、收尾困难；灵活但不可靠 | 有一定条理但不苛刻；关键事情能守住 | 有序、守时、目标导向；容易僵化和过劳 |
| 外向性 E | 独处补充能量；社交后需要恢复；话少但不一定害羞 | 能社交也能独处；不主动但不排斥 | 人群中补充能量；主动、话多、节奏快 |
| 宜人性 A | 直率、立场优先、不怕冲突；容易被读成冷或攻击性 | 大体合作但有底线 | 温和、体谅、以关系为先；容易过度让步 |
| 神经质 N | 情绪平稳、抗压；也可能对他人情绪不敏感 | 情绪有起伏但可控 | 感受敏锐、情绪起伏大、容易反刍；也更早察觉风险 |

**注意**：低神经质不等于"好"，要写出它的代价（对危险不敏感、共情他人痛苦时迟钝）。
高宜人性不等于"好"，要写出代价（被占便宜、不敢提要求）。每一档都必须有代价。

## 组合交互（写出这个，画像才不像五段独立文字拼起来的）

至少在 summary 或某个生活领域里，明确写出**两个维度互相拉扯或互相放大**的地方。常见的强交互：

- 高 N + 低 E → 反刍无人稀释，容易在独处里越想越糟
- 高 N + 低 A → 冲突后怨气累积且不肯先退
- 高 N + 低 C → 拖延引发自责，自责继续拖延（恶性循环）
- 高 N + 高 C → 高标准 + 情绪敏感 = 过劳与自我苛责
- 低 N + 低 A → 不容易被情绪影响也不容易被他人情绪影响，常被读成冷酷
- 高 O + 低 C → 想法多但收不了尾
- 高 O + 高 C → 想法能落地，最容易出成果的组合之一，但容易把自己逼死
- 高 E + 低 A → 有魅力也有杀伤力，长期关系里伤人
- 低 E + 高 A → 想维系关系但不主动，容易被动等待
- 低 O + 高 C → 高度可靠，但环境突变时调整慢
- 全中 → 行为由场合决定而非倾向决定；辨识度低是主要代价

不要机械套用；只写这一格真正成立的那几条。

## 输出格式（严格 JSON）

每个画像一个对象：

```json
{
  "cell": "O中C高E高A高N低",
  "lead": "一句话概括，18-28 字，不用句号结尾",
  "summary": "你大概是这样的人。110-160 字。必须包含至少一处维度交互。",
  "life": "生活/日常/独处与作息。80-120 字。",
  "friends": "交友与维系朋友。80-120 字。",
  "love": "恋爱与亲密关系。80-120 字。",
  "work": "工作与协作。80-120 字。",
  "pros": ["优点1", "优点2", "优点3"],
  "cons": ["缺点1", "缺点2", "缺点3"],
  "practice": ["可以练的具体动作1", "动作2", "动作3"]
}
```

**字数口径（务必统一）**：所有「字」指**剔除空白后的全部字符，含标点**。
两种口径的结论差别很大——`lead` 在含标点口径下只有 2 条越界，不含标点口径下有 45 条，
差 22 倍。验收脚本 `tools/verify_corpus.py` 用的是含标点口径。

- `pros` / `cons` 每条 8–20 字，是短语不是句子。
- `practice` 每条 20–45 字，必须是**可执行的具体动作**，不是"要多沟通"这种废话。
  好的例子："兴奋的当下不要答应任何事，隔 24 小时还想做再答应。"
- 全部字段必填，不得留空。

## 区分度要求（最重要的质量标准）

每个画像必须和它的**邻居**明显不同。邻居 = 只有一个维度差一档的格子（每格最多 10 个邻居）。
写完一批后自检：把相邻两格的文字并排看，如果换掉标题分不出来，就是没写好，重写。

具体做法：让**差异维度真正驱动内容**。比如 `O中C高E高A高N低` 和 `O中C高E高A高N中` 的区别
应该体现在"压力下的表现""对批评的反应""恢复速度"上，而不是只改几个形容词。

## 两个已通过的样例（照这个密度和语气写）

### O中C中E中A中N中

lead: 五个维度都落在中间，行为更多由场合决定

summary: 五个维度都落在人群中间地带。这不是"没有性格"，而是你的行为更多由场合决定，
而不是由某个突出的倾向决定——同一件事，换个环境你可能给出完全不同的反应，这在高分或
低分的人身上要少见得多。代价是你缺少一个"默认设置"，做选择时容易反复权衡，因为没有
哪个倾向强到能帮你直接排除选项。

friends: 你在大多数群体里都待得住，但也很少成为核心。朋友对你的评价往往是"挺好相处"
而不是某个具体标签。要留意的是：中等外向的人最容易高估自己社交上的主动性——你觉得
"我们常联系"的朋友，可能已经半年没收到你消息了。

practice: ["给自己造一个人为的极端：挑一件事刻意做到过头，用外部规则补上你天生没有的那股劲。"]

### O高C低E高A低N高

lead: 想法很多、情绪很满、收尾很差

summary: 你的组合里有三股力量在互相拽：开放性和外向性推着你不断开始新东西，低尽责性
让你收不了尾，高神经质让每一次收不了尾都变成一次自我攻击。你不是懒，你是启动成本极低
而维持成本极高。

love: 你会是热烈的追求者和难缠的伴侣。高神经质让你把对方的小反应放大，低宜人性让你
在争执里不肯先退。最该练的一句话是"我现在情绪上来了，等我半小时再聊"——这一句能挡掉
你大半的破坏性冲突。

practice: ["把承诺和兴奋分开：兴奋的当下不要答应任何事，隔 24 小时还想做再答应。"]
